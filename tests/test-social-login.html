Setup Instructions
  1. Configure Admin Panel:
    • Go to Advanced Settings
    • Enable Google/Facebook Login
    • Add OAuth Client IDs and Secrets
    • Save settings
  2. Test API:
    • Click "Test API" button above
    • Verify Google/Facebook enabled status matches admin settings
  3. Flutter App:
    • Hot restart the Flutter app
    • Go to Login screen
    • Social login buttons will appear based on admin settings
Note: The Flutter app fetches configuration on startup. After changing settings in admin panel, restart the Flutter app to see changes.
