# Archive Folder

This folder contains sample files, one-time setup utilities, and deprecated scripts that are no longer actively used but kept for reference.

## 📂 Contents

### Sample Files
- **add_live_updates_sample.php** - Sample code for adding live updates
- **generate_sample_articles.php** - Article generation utility
- **test_banner.json** - Test banner data

### Setup Utilities (One-Time Use)
- **setup-uploads.php** - Initial uploads directory setup
- **setup-podcasts.php** - Podcast system initialization
- **setup-app-settings.php** - App settings initialization

## 📋 Purpose

Files are moved to archive when they are:
- ✅ One-time setup scripts that have been executed
- ✅ Sample/demo files no longer needed for active development
- ✅ Deprecated utilities replaced by better solutions
- ✅ Test data files from initial development
- ✅ Reference implementations kept for historical context

## ⚠️ Important Notes

1. **Do Not Execute**: These scripts are archived and may not work with current database structure
2. **Reference Only**: Use as reference for understanding initial implementation
3. **Not Maintained**: Files in archive are not kept up-to-date
4. **Backup Purpose**: Kept for historical context and emergency recovery

## 🔍 When to Use Archive Files

### Sample Files
Use sample files when:
- Learning how a feature was initially implemented
- Understanding data structure examples
- Creating new similar features

### Setup Utilities
Use setup utilities when:
- Resetting system to initial state (development only)
- Understanding initial configuration steps
- Troubleshooting setup-related issues

## 🗑️ Cleanup Policy

Files can be safely deleted from archive if:
- More than 6 months old
- Feature has been completely removed
- Replaced by better documented solutions
- No historical value remaining

## 📦 Archive vs Tests

**Archive** contains:
- One-time use scripts (already executed)
- Sample/demo files
- Deprecated implementations

**Tests** contains:
- Active testing scripts
- Debug utilities
- Verification tools
- Scripts run regularly

## 🔄 Moving to Archive

To archive a file:
1. Ensure it's no longer needed for active development
2. Verify it's documented elsewhere (if needed)
3. Move to this folder
4. Update this README with entry
5. Set deletion date (typically 6 months)

## 💾 Recovery

If you need to restore an archived file:
1. Check if current system is compatible
2. Review for any security updates needed
3. Test in development environment first
4. Update as needed for current system
5. Move to appropriate active folder

## 🎯 Best Practices

1. **Don't Archive Active Code**: Only archive truly obsolete/completed files
2. **Document Why**: Note reason for archiving in this README
3. **Set Expiration**: Mark when files can be safely deleted
4. **Keep Clean**: Regularly review and remove very old files
5. **Backup Important**: Keep critical reference files backed up elsewhere
